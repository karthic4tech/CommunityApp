## 🎨 CUSTOMIZE

### Change Colors
Edit `home-beta.component.scss` - Update CSS variables:
```scss
:root {
  --orange: #your-color;
  --ink: #your-color;
  --charcoal: #your-color;
  /* ... */
}
```

### Change Content
Edit `home-beta.component.html` - Update text/images

### Change Fonts
Edit `home-beta.component.scss` - Update font-family

### Change Spacing
Edit `home-beta.component.scss` - Update padding/margins

---

## 🖼️ ADD IMAGES

Replace Unsplash URLs in SCSS with your images:

```scss
// Hero image
.hero-image {
  background: url('your-image.jpg') center/cover;
}

// Circle photo
.circle-photo {
  background: url('your-image.jpg') center/cover;
}

// Heritage photo
.heritage-photo {
  background: url('your-image.jpg') center/cover;
}

/* ... and other sections */
```
