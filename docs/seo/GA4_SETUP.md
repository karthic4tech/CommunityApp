# GA4 / GTM setup

The Angular app now includes production-only, consent-gated Google Tag Manager support. See [docs/analytics/GA4_IMPLEMENTATION.md](../analytics/GA4_IMPLEMENTATION.md) for the configured IDs, supported events, privacy safeguards, GTM tag/trigger instructions, and testing steps.

The application IDs are public configuration. GTM tags and GA4 event mappings must still be created and published in the owner's GTM workspace; this repository cannot make remote GTM/GA4 changes.
