# CDM 360 organic growth plan

This plan uses no paid SEO subscriptions, purchased backlinks, fabricated reviews, or guaranteed ranking/traffic forecasts. Treat Search Console and consented enquiry data as the measurement sources after configuration.

## Days 1–30: crawlability and trust

- Deploy the generated static build only after Cloudflare preview confirms public HTML, metadata, JSON-LD, robots and sitemap behavior.
- Verify `cdm360.in` in Search Console using the owner-provided DNS TXT record; submit the sitemap and inspect home, tourism, hotels, one service detail and one category.
- Audit indexing reports for duplicate canonicals, soft 404s, blocked URLs and crawled-not-indexed pages. Record the first available impressions/clicks baseline.
- Review each currently published/verified service profile with its provider: public business name, category, location, contact visibility, description and useful original images. Unpublish or correct low-quality/stale records through the existing admin workflow, not SEO scripts.
- Ask a local editor to review the existing bilingual `/tourism` guide and its official sources. Confirm current temple access guidance, Pichavaram operations and any practical travel details directly with authoritative sources.
- Provide useful internal links from the existing tourism hub to actual published hotels, dining and transport categories. Preserve the directory/enquiry model; describe hotel enquiries as requests, not instant reservations.

## Days 31–60: expand only where evidence supports it

- Compare the latest 28-day Search Console period with the first available baseline. Identify queries/pages with relevant impressions, CTR opportunities and indexing exclusions.
- Improve existing category and provider copy using verified service information; prioritize complete descriptions, accurate locations, public contact preferences and image alt text.
- If Search Console shows meaningful demand and local editors can add original verified value, prepare a focused Nataraja Temple or Pichavaram guide. Cite official sources and record review dates; do not repeat the current tourism page with swapped keywords.
- If a genuinely published, verified cab operator confirms route coverage and enquiry handling, improve the real transport category and add a sourced Chidambaram–Pichavaram planning section. Do not claim fare, route availability or journey duration without confirmation.
- Add Tamil editorial review by fluent local reviewers. Do not publish machine-only translations of visitor rules, safety information or booking details.

## Days 61–90: conversion quality and maintenance

- Review Search Console landing pages, query/device/country and CTR. Refresh pages where impressions, user questions or authoritative source changes justify a revision.
- Track only consented, non-PII GA4 page/enquiry events after an owner-approved consent interface and real Measurement ID are installed. Compare hotel enquiry completions with backend-confirmed inserts, not button clicks alone.
- Ask partners whether enquiries were relevant and whether listing details remain accurate. Use the existing admin-managed status process; do not mark a request booked without customer acceptance and partner confirmation.
- Rebuild and deploy after content/listing publication so generated sitemap and prerender output refresh. Monitor for stale URLs and removed/unapproved listings.
- Review mobile CWV reports when sufficient field data exists; use repeatable Lighthouse lab runs in the interim and label them as lab data.

## Ongoing editorial guardrails

- Keep a single useful `/tourism` hub until a separate page can be genuinely distinct and locally reviewed.
- Do not create pages for every keyword, location, itinerary or category without useful public inventory and unique content.
- Do not publish prices, ratings, opening hours, reviews, transport availability or temple/boat schedules unless verified from a reliable source.
- Do not expose private booking/customer details in HTML, JSON-LD or analytics.
- Optimize internal links and provider profiles before seeking external mentions. Earn links through useful local resources and genuine community partnerships; never buy backlinks.
- Record actual changes and Search Console/GA4 observations; organic results can fluctuate and are not guaranteed.
