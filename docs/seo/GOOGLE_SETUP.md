# Google Search Console and analytics setup

The owner reports that Search Console is verified and the sitemap has been submitted. This repository does not modify DNS or Google account settings.

For the supplied Google Tag Manager and GA4 IDs, app instrumentation, consent behavior, GTM tag configuration, and verification instructions, see [docs/analytics/GA4_IMPLEMENTATION.md](../analytics/GA4_IMPLEMENTATION.md). The code loads the configured GTM container only after consent; the GA4 Google tag must still be created and the GTM container published in the owner's GTM account.
