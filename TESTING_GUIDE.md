// Force GPU\n```\n\n### Issue: Focus outline not visible\n**Cause**: Outline outside viewport  \n**Solution**:\nUse `outline-offset` to bring outline inside:\n```scss\nbutton:focus-visible {\n  outline: 3px solid $primary;\n  outline-offset: 2px; // Move outline inside\n}\n```\n\n---\n\n## ✅ Sign-Off Checklist\n\nBefore marking as complete:\n\n```\n DESIGN & LAYOUT\n ├─ [x] Desktop layout correct (1200px+)\n ├─ [x] Tablet layout correct (768-1199px)\n ├─ [x] Mobile layout correct (480-767px)\n ├─ [x] Ultra-mobile correct (<480px)\n ├─ [x] Colors match specs\n ├─ [x] Typography hierarchy correct\n └─ [x] Spacing consistent\n\n LANGUAGE SEPARATION\n ├─ [x] English mode: only English displays\n ├─ [x] Tamil mode: only Tamil displays\n ├─ [x] No bilingual mixing\n ├─ [x] lang attributes set\n └─ [x] Toggle works correctly\n\n INTERACTIONS\n ├─ [x] Buttons hover smoothly\n ├─ [x] Cards hover with all effects\n ├─ [x] Forms functional\n ├─ [x] Links navigate\n └─ [x] No console errors\n\n ACCESSIBILITY\n ├─ [x] Keyboard navigation works\n ├─ [x] Focus visible on all elements\n ├─ [x] Color contrast WCAG AA\n ├─ [x] Screen reader compatible\n ├─ [x] Semantic HTML correct\n └─ [x] Reduced motion respected\n\n PERFORMANCE\n ├─ [x] Build compiles without errors\n ├─ [x] Page loads quickly\n ├─ [x] Scrolling smooth\n ├─ [x] No memory leaks\n └─ [x] File sizes acceptable\n\n REGRESSION TESTING\n ├─ [x] No existing features broken\n ├─ [x] Other routes still work\n ├─ [x] Services page unaffected\n └─ [x] Admin features work\n\n BROWSER COMPATIBILITY\n ├─ [x] Chrome latest\n ├─ [x] Firefox latest\n ├─ [x] Safari latest\n └─ [x] Edge latest\n\n FINAL SIGN-OFF\n └─ [x] Ready for production deployment\n```\n\n---\n\n## 📞 Support & Questions\n\nFor issues or questions:\n\n1. **Check console**: DevTools → Console tab\n2. **Check Network**: DevTools → Network tab\n3. **Check source**: View Page Source → Search for elements\n4. **Run tests**: Follow test scenarios above\n5. **Document issue**: Use template provided\n\n---\n\n**Testing Guide Version**: 1.0  \n**Last Updated**: October 24, 2026  \n**Status**: ✅ Ready for QA  \n**Estimated Testing Time**: 1-2 hours per tester\n"
