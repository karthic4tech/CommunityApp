# Home Beta - Visual Design Patterns & Component Library\n\n## Quick Reference Guide\n\n### Section Layout Pattern\n```\n┌─────────────────────────────────────────────────┐\n│  SECTION CONTAINER (max-width: 1400px)          │\n│  ┌───────────────────────────────────────────┐  │\n│  │  Section Header                           │  │\n│  │  ├─ Heading (h2)                          │  │\n│  │  └─ Subtitle (p)                          │  │\n│  └───────────────────────────────────────────┘  │\n│                                                 │\n│  ┌──────────────┐  ┌──────────────┐            │\n│  │   Card 1     │  │   Card 2     │  ...       │\n│  │              │  │              │            │\n│  │  Responsive  │  │   Grid       │            │\n│  │  auto-fit    │  │              │            │\n│  └──────────────┘  └──────────────┘            │\n└─────────────────────────────────────────────────┘\n```\n\n---\n\n## Reusable Card Components\n\n### 1. Feature Card (4 Color Variants)\n```\n┌─────────────────────────┐\n│  [56x56 Icon]           │  ← Feature icon (orange/teal/gold/slate)\n│  Feature Title          │  ← Bold, color-matched\n│                         │\n│  Feature description    │  ← Muted gray text\n│  text that explains     │\n│  the feature benefit.   │\n│                         │\n│  Learn more ➜          │  ← Link with arrow animation\n└─────────────────────────┘\n\nHover: -8px lift, primary border, shadow enhancement\n```\n\n**CSS Classes Used**:\n- `.feature-card` - Base card styling\n- `.feature-orange|teal|gold|slate` - Color variants\n- `.feature-icon` - Icon wrapper\n- `.feature-link` - \"Learn more\" link\n\n**Responsive**: `grid-template-columns: repeat(auto-fit, minmax(260px, 1fr))`\n\n---\n\n### 2. Service Category Card (Large)\n```\n┌─────────────────────────┐\n│   [72x72 Icon]          │  ← Gradient background (orange to darker)\n│   ↓ hover: scale, rotate │\n│                         │\n│   Service Category      │  ← Bold title\n│                         │\n│   Category description  │  ← Muted text, 2-3 lines\n│   explaining the        │\n│   service offerings.    │\n│                      ↗│  ← Arrow pill badge (on hover)\n└─────────────────────────┘\n\nHover: -12px lift, icon scale(1.1) rotate(-5deg), arrow inverts\n```\n\n**CSS Classes Used**:\n- `.service-card` - Base card\n- `.service-icon-wrapper` - Icon with gradient\n- `.service-arrow` - Arrow pill badge\n\n**Responsive**: `grid-template-columns: repeat(auto-fit, minmax(280px, 1fr))`\n\n---\n\n### 3. Step/Process Card (How It Works)\n```\n   ╭─────╮\n   │  1  │         Step Title\n   ╰─────╯\n      ↓\n   Step description\n   explaining the\n   process.\n\n   ─────────────  ← Desktop only: gradient divider\n\n   ╭─────╮\n   │  2  │         Next Step\n   ╰─────╯\n```\n\n**CSS Classes Used**:\n- `.step-item` - Step container\n- `.step-number` - Circular badge with gradient\n- `.step-divider` - Hidden on mobile, visible on desktop\n\n**Responsive Grid**:\n- Desktop (1024px+): `grid-template-columns: 1fr auto 1fr auto 1fr` (5 columns)\n- Tablet/Mobile: `grid-template-columns: 1fr` (single column, no dividers)\n\n---\n\n## Button Styles Library\n\n### Primary Button (Orange)\n```\n┌───────────────────┐\n│  Explore Services │\n│      ↗  icon      │  ← Arrow on                 │  ← Rounded container\n│          ╭─────────────╮              │\n│          │   [Icon]    │              │\n│          ├─────────────┤              │\n│          │  Slide      │              │\n│          │  Title      │              │\n│          │             │              │\n│          │  Slide      │              │\n│          │  Description              │\n│          ╰─────────────╯              │\n│                                        │\n│        ◀  ●  ○  ○  ▶                 │  ← Controls below\n└────────────────────────────────────────┘\n\nCarousel Fade Transition: 0.6s cubic-bezier(0.4, 0, 0.2, 1)\nSlide Content Animation: slideUp 0.8s (fade in + translate from bottom)\n```\n\n**Carousel Controls**:\n- **Dots**: Inactive (10px circles), Active (30px pill)\n- **Arrows**: White bg, hover primary, 0.3s transition\n- **Icons**: Bootstrap Icons (bi-chevron-left, bi-chevron-right)\n\n**CSS Animations**:\n```scss\n.carousel-slide {\n  opacity: 0;\n  visibility: hidden;\n  transition: opacity 0.6s cubic-bezier(0.4, 0, 0.2, 1),\n              visibility 0.6s cubic-bezier(0.4, 0, 0.2, 1);\n}\n\n.carousel-slide.active {\n  opacity: 1;\n  visibility: visible;\n}\n\n@keyframes slideUp {\n  from { opacity: 0; transform: translateY(20px); }\n  to { opacity: 1; transform: translateY(0); }\n}\n```\n\n---\n\n## Color Application Examples\n\n### Orange min and max sizes based on viewport */\nh1 { font-size: clamp(2.2rem, 5vw, 3.8rem); }\nh2 { font-size: clamp(2rem, 4vw, 3rem); }\np  { font-size: clamp(0.95rem, 1.5vw, 1.05rem); }\n```\n\n### Fluid Spacing\n```scss\n/* Responsive padding/gaps */\npadding: clamp(1.5rem, 5vw, 4rem);\ngap: clamp(2rem, 6vw, 5rem);\n```\n\n### Auto-fit Grid\n```scss\n/* Automatically adjusts number of columns based on viewport */\ngrid-template-columns: repeat(auto-fit, minmax(260px, 1fr));\n```\n\n---\n\n## Animation Library\n\n### Slide Up Animation\n```scss\n@keyframes slideUp {\n  from {\n    opacity: 0;\n    transform: translateY(20px);\n  }\n  to {\n    opacity: 1;\n    transform: translateY(0);\n  }\n}\n\n.slide-content {\n  animation: slideUp 0.8s cubic-bezier(0.4, 0, 0.2, 1) backwards;\n}\n```\n\n### Hover Lift (Cards)\n```scss\n.card:hover {\n  transform: translateY(-8px);  /* Service cards: -12px */\n  box-shadow: 0 20px 40px rgba(0, 0, 0, 0.1);\n  transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);\n}\n```\n\n### Scale & Rotate (Icons)\n```scss\n.service-icon-wrapper:hover {\n  transform: scale(1.1) rotate(-5deg);\n  transition: all 0.3s ease;\n}\n```\n\n### Dot Expansion (Carousel)\n```scss\n.dot {\n  width: 10px;\n  height: 10px;\n  transition: all 0.3s ease;\n}\n\n.dot.active {\n  width: 30px;  /* Expands to pill shape */\n  border-radius: 999px;\n  background: box-sizing\n\n✅ **JavaScript**\n- OnPush change detection (only updates on input change)\n- No DOM manipulation\n- Pure functions for carousel logic\n- Lazy loading of component chunk\n\n✅ **Images**\n- Zero external images (uses Bootstrap Icons web font)\n- No Image optimization needed\n- SVG-based icons scale perfectly\n\n---\n\n## How to Extend\n\n### Add a New Feature
